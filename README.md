# Abartılı Türk Kahvesi Falı Yorumcusu

## Bu Ne?

Bu, dünyanın en ciddi, en abartılı ve en gereksiz Türk kahvesi falı yorumcusudur. 

Gerçekten çalışır. Gerçekten yorum yapar. Gerçekten hiçbir işe yaramaz.

## Nasıl Çalışır?

1. Python 3 yükleyin (ciddi).
2. `python falci.py` çalıştırın.
3. Fincanınızı hayal edin.
4. Enter'a basın.
5. Saçma bir yorum alın.
6. Şaşırın.

## Özellikler

- %100 rastgele
- %0 doğruluk
- 3 saniye bekleme (gerçekçilik için)
- Hiçbir bilimsel temeli yok
- Açık kaynak (neden?)

## Uyarı

Bu program hayatınızı değiştirmez. Fincanınız da değiştirmez. Sadece zamanınızı çalar.

## Lisans

Kullanmak serbest. Yorumların doğru olduğunu iddia etmek yasak.
